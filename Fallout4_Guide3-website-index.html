FALLOUT 4 APOCALYPSE TOOLKIT

Creation Kit Modding Master Reference Guide.

🛠️ CHAPTER 1: PREPARE YOUR TOOLS

Platform Rules:

PC & Xbox support all custom files. PS5 supports textures/meshes (Max 15 GB, no UI). PS4 allows vanilla asset copies only.

  • BAE: Extracts assets from base archives.
  • Paint.NET / GIMP: Edits asset texture sheets.
  • Creation Kit (CK): Main game database tool editor.
  • NifSkope: Adjusts 3D mesh node rendering data.

🖌️ CHAPTER 2: NON-CUSTOM RESKINS (PS4 COMPATIBLE)

Step 1: Extract Textures

  1. Open BAE. Load Fallout4 - Textures.ba2.
  2. Search for your target item name and extract the _d.dds file.

Step 2: Add Dirt and Rust

  1. Open texture in your editor. Overlay a rust image layer.
  2. Set layer blend to Multiply. Lower opacity to blend details.
  3. Save as DDS with BC7 Linear compression. Move to Data\Textures\Apocalypse\.

Step 3: Creation Kit Link

  1. In CK, open Miscellaneous > TextureSet. Right-click and select New.
  2. Link your texture path. Find your weapon in Items > Weapon.
  3. Change its ID to create a duplicate. Swap default texture with your new form. Save your mod.

📐 CHAPTER 3: CUSTOM ASSETS (PC, XBOX, PS5)

  1. Save your custom mesh asset file to Data\Meshes\Apocalypse\[Name].nif.
  2. Open CK. Find a base game weapon or armor template form to clone.
  3. Change the ID to a unique name. Click Model / Art and load your .nif mesh file. Save.

💡 CHAPTER 4: NIFSKOPE MESH FIXES

  1. Open your .nif file in NifSkope. Click the item surface.
  2. In Block List, select BSLightingShaderProperty. Go to Block Details below.
  3. Set Specular Strength to 1.0 or 2.0. Set Specular Color to dark grey.
  4. Uncheck SF_Own_Emit and SF_Glow_Shader to prevent dark room lighting bugs. Save mesh.

🎒 CHAPTER 5: APOCALYPSE CONFIGURATIONS

Tuning Summary:

Weapons: Change damage, lower Speed to 0.80. Food: Add RadDamageSpell. Ghouls: Set Speed to 135.

  • Sorting Tags: Rename items with bracket prefixes like |Scrap| or (Weapon).
  • Survival: Tag food with parasite and illness risk parameters inside item menus.

📦 CHAPTER 6: LOOT DROPS & TRADERS

  • Loot Lists: Go to Items > LeveledItem. Open LLI_Raider_Weapons and inject your new weapon ID.
  • Vendors: Open LL_Vendor_Weapon_General and insert your custom item entry form.

🛠️ CHAPTER 7: WORKBENCH CRAFTING RECIPES

Allow players to build your custom apocalypse weapons and cook raw zombie meat at specialized settlement stations.

  1. In the CK Object Window, navigate to Items > ConstructibleObject. Right-click the grid and select New.
  2. Assign a recipe identity ID starting with the recipe prefix (e.g., Recipe_Zombie_RustyBat).
  3. In the Required Items panel on the left, right-click and add your raw components (e.g., select c_steel or c_wood and define their quantities).
  4. In the Created Object dropdown list on the right, link your custom apocalypse weapon or item form.
  5. Set the Workbench Keyword to map where it can be crafted:
    • For gear: Select WorkshopWeaponWorkbench or WorkshopArmorWorkbench.
    • For consumables/meat: Select WorkshopCookingStation.

🔫 CHAPTER 8: WEAPON AMMUNITION CONFIGURATIONS

Alter what type of custom ammunition casings your improvised weapon targets, or swap clean calibers for scrap variations.

  1. Open your custom weapon profile from the Items > Weapon tree.
  2. Locate the Ammo / Combat configuration page framework tab.
  3. Find the Ammo dropdown selection field. Swap standard pristine choices for dirty, scrap calibers (e.g., swap out 5.56mm for Ammo38 or a custom radioactive round).
  4. To adjust how NPCs use ammo, locate the Don't Use Ammo checkbox toggle. Uncheck this box to force survivors and raiders to track their remaining clip counts realistically during a horde scenario.

🔊 CHAPTER 9: CUSTOM VOICE & AUDIO

Step 1: Background Tracks

  1. Open MultiXWM. Add your .wav tracks. Compress to 48 kbps for music tracks or 32 kbps for wind/drone loops to save console file storage space.
  2. Click convert. Save into Data\Music\Special\.

Step 2: Character Voice

  1. Format voice clip to Mono, 44100Hz, 16-bit WAV.
  2. Drag file onto Fallout 4\Tools\Audio\FuzXWM.exe to compile it into a console-safe .fuz file.

🎥 CHAPTER 10: MAIN MENU UI

  • PC / Xbox Video: Compress custom video with RAD Video Tools. Name it MainMenuLoop.bk2. Save in Data\Video\.
  • PlayStation Text: In CK, open File > Localization > String Editor. Overwrite entry text sMainMenuTitle with: FALLOUT: APOCALYPSE.

🎬 CHAPTER 11: ANIMATED LOADING SCREENS

  1. In CK, open Miscellaneous > LoadScreen. Right-click and choose New.
  2. Click Model and link your custom zombie mesh file.
  3. Message details: Tip: Feral Ghouls are faster now. Aim for the legs to slow down the horde.
  4. Add a new blank condition line. Set the Multiplier setting tracker to 2.0 for random load spawns.

🎨 CHAPTER 12: STOREFRONT ARTWORK DIMENSIONS

  • Store Tile Graphic: Exactly 512 x 512 pixels size square canvas format.
  • Gallery Page Screenshots: Exactly 1920 x 1080 pixels size landscape image format.
  • Upload: Log in via CK. Select Upload to Creations. Add artwork and click Publish.

💾 CHAPTER 13: TEXTURE & BUNDLE EXPORTS

  • DDS Export: Use Paint.NET. Save as DDS BC7 Linear. Check Mip Maps box to stop texture flicker.
  • Archive2 Packing: Open Archive2.exe. Add your Meshes, Interface, Sound, and Music asset folders. Save name string exactly as: [YourModName] - Main.ba2.
